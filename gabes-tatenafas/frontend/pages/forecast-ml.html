Courbes ROC (multi-classes + macro)

📚 Explication scientifique complète
  • Rôle : mesurer la capacité du modèle à séparer les classes de qualité de l’air (Bon / Modéré / Mauvais / Dangereux).
  • Principe mathématique : la courbe trace le taux de vrais positifs (TPR = recall) contre le taux de faux positifs (FPR) pour tous les seuils de décision. L’AUC est l’aire sous la courbe (probabilité qu’un cas positif tiré au hasard soit mieux classé qu’un négatif).
  • Axes / couleurs : X = FPR (fausses alertes), Y = TPR (bonnes détections). Chaque couleur = une classe ; la ligne pointillée grise = hasard (AUC 0,5).
  • Interprétation : plus la courbe « monte à gauche », meilleur est le modèle. AUC > 0,9 = excellent.
  • Limites : l’AUC peut être optimiste sur classes déséquilibrées → compléter par la courbe Précision-Rappel.
  • Erreur à éviter : confondre AUC élevée et bonne calibration ; une AUC forte ne garantit pas des probabilités fiables.

Graphe 1 — TreeSHAP : importance globale (modèles à arbres) ★

Version moderne 2026 : valeurs de Shapley exactes calculées par l’algorithme TreeSHAP (Lundberg 2020) directement sur le Random Forest — rapide et sans approximation.
📚 Explication scientifique complète
  • Rôle : classer les variables (polluants, météo) par leur contribution moyenne à la prédiction de l’AQI.
  • Principe mathématique : la valeur de Shapley φᵢ répartit équitablement la prédiction entre variables selon la théorie des jeux coopératifs ; TreeSHAP la calcule exactement en O(arbres × feuilles).
  • Axes / couleurs : Y = variables, X = |importance| moyenne normalisée ; barre plus foncée = plus importante.
  • Interprétation : la variable du haut est le principal moteur de la qualité de l’air à Gabès.
  • Limites : l’importance globale masque les effets locaux (voir Waterfall) et les interactions (voir DeepSHAP).
  • Erreur à éviter : interpréter l’importance comme une causalité ; c’est une association apprise par le modèle.

Graphe 2 — SHAP+Deep : DeepSHAP (réseau profond) vs TreeSHAP (arbres) ★

Barres grises = importance TreeSHAP (arbres), barres violettes = importance DeepSHAP (réseau de neurones). L’écart révèle les effets non-linéaires et de seuil capturés par le deep learning.
📚 Explication scientifique complète
  • Rôle : comparer deux familles d’explicabilité pour voir ce que le réseau profond « voit » en plus.
  • Principe mathématique : DeepSHAP combine DeepLIFT et les valeurs de Shapley pour propager les contributions à travers les couches du réseau (référence + règle de chaîne).
  • Axes / couleurs : Y = variables, X = importance normalisée ; gris = TreeSHAP, violet = DeepSHAP.
  • Interprétation : une variable haute en DeepSHAP mais basse en TreeSHAP a un effet non-linéaire (seuil, saturation) que les arbres capturent moins finement.
  • Limites : DeepSHAP dépend de l’échantillon de référence et nécessite TensorFlow.
  • Erreur à éviter : comparer les valeurs absolues des deux méthodes ; comparez plutôt les rangs.

SHAP Beeswarm — distribution par instance

Chaque point = une observation réelle. Couleur : bleu = valeur basse, rouge = valeur haute du polluant.
📚 Explication scientifique complète
  • Rôle : montrer à la fois l’importance ET le sens de l’effet de chaque variable, sur toutes les observations.
  • Principe : position horizontale = valeur SHAP (impact sur l’AQI) ; densité verticale = nombre d’observations ; couleur = valeur de la variable.
  • Axes / couleurs : X = impact SHAP (négatif → baisse l’AQI, positif → l’augmente) ; rouge = valeur haute, bleu = valeur basse.
  • Interprétation : si les points rouges d’un polluant sont à droite, alors une forte concentration augmente l’AQI (logique attendue).
  • Limites : lecture délicate quand beaucoup de variables se chevauchent.
  • Erreur à éviter : lire un seul point comme une règle générale.

PDP — Partial Dependence (effet marginal) ★

Effet moyen de chaque polluant sur l’AQI prédit, toutes choses égales par ailleurs.
📚 Explication scientifique complète
  • Rôle : visualiser la forme de la relation entre un polluant et l’AQI (linéaire ? seuil ? saturation ?).
  • Principe mathématique : on fixe une variable à une valeur donnée pour toutes les observations, on moyenne les prédictions, puis on balaie une grille de valeurs.
  • Axes / couleurs : X = valeur réelle du polluant, Y = AQI moyen prédit ; une couleur par variable.
  • Interprétation : pente forte = influence forte ; un « coude » = effet de seuil sanitaire.
  • Limites : suppose l’indépendance des variables ; trompeur en cas de forte corrélation (compléter par ICE/ALE).
  • Erreur à éviter : extrapoler hors de la plage de données réelles.

Permutation Importance (model-agnostic) ★

Importance mesurée par la dégradation des performances quand on mélange une variable.
📚 Explication scientifique complète
  • Rôle : confirmer l’importance des variables indépendamment de SHAP, avec une méthode robuste et universelle.
  • Principe mathématique : on permute aléatoirement les valeurs d’une variable et on mesure l’augmentation de l’erreur ; plus l’erreur monte, plus la variable est cruciale.
  • Axes / couleurs : Y = variables, X = perte de performance normalisée.
  • Interprétation : un accord TreeSHAP + Permutation renforce la confiance dans le classement des variables.
  • Limites : sous-estime les variables corrélées (l’info reste disponible via la variable jumelle).
  • Erreur à éviter : comparer directement l’échelle de Permutation à celle de SHAP (unités différentes).

SHAP local — Waterfall (pourquoi cet AQI ?)

📚 Explication scientifique complète
  • Rôle : expliquer une prédiction précise : décomposer l’AQI d’une observation en contributions individuelles.
  • Principe mathématique : prédiction = valeur de base E[f(x)] + somme des φᵢ (valeurs SHAP locales).
  • Axes / couleurs : Y = variables, X = AQI ; barre rouge = pousse l’AQI vers le haut, barre bleue = vers le bas.
  • Interprétation : on lit du bas (base) vers le haut (prédiction) la chaîne des effets.
  • Limites : valable pour cette instance seulement.
  • Erreur à éviter : généraliser une explication locale à tout le jeu de données.

SHAP Decision Plot — chemin de décision ★

Trajectoire cumulée : de la valeur de base jusqu’à la prédiction finale, variable par variable.
📚 Explication scientifique complète
  • Rôle : montrer l’accumulation des effets menant à la décision, plus lisible que le Waterfall quand il y a beaucoup de variables.
  • Principe mathématique : somme cumulée des valeurs SHAP ajoutées une à une à partir de la valeur de base.
  • Axes / couleurs : Y = AQI cumulé, X = variables ajoutées ; point rouge = l’étape augmente l’AQI, bleu = le réduit.
  • Interprétation : une marche verticale marquée signale une variable décisive pour ce cas.
  • Limites : comme le Waterfall, c’est une explication locale.
  • Erreur à éviter : comparer des chemins d’instances trop différentes sans contexte.

DLIME — explication locale déterministe (stable) ★

Vert = réduit l’AQI · Rouge = augmente l’AQI.
📚 Explication scientifique complète
  • Rôle : expliquer localement une prédiction avec un modèle simple, de manière reproductible (contrairement au LIME classique aléatoire).
  • Principe mathématique : DLIME (Zafar & Khan 2019) remplace l’échantillonnage aléatoire par un clustering hiérarchique + KNN, puis ajuste une régression locale pondérée → même résultat à chaque exécution.
  • Axes / couleurs : Y = variables, X = poids local ; rouge = augmente l’AQI, vert = le diminue.
  • Interprétation : pour un jury, la stabilité est essentielle : deux exécutions donnent la même explication.
  • Limites : approximation locale ; valable dans un petit voisinage de l’instance.
  • Erreur à éviter : comparer les poids LIME à des valeurs SHAP (méthodes et échelles différentes).
