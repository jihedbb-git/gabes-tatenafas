How the hybrid pipeline works

  • Model A (classical ML) — auto-regressive AR(7) with day-of-week Fourier features, fitted by ordinary least squares with ridge regularization.
  • Model B (DL-inspired) — three exponential smoothers (α = 0.2, 0.5, 0.8) blended through sigmoid weights learned by gradient descent.
  • Ensemble — α·A + (1−α)·B, where α ∈ [0,1] is chosen by RMSE-minimizing grid-search on the held-out validation slice (last 20 % of the series).
  • Data — pulled from risk_scores + risk_scores_augmented (synthetic data injected by the augmentation module).
  • Optional Python sidecar — scripts/train_forecast.py upgrades the pipeline to a real XGBoost + LSTM ensemble.
