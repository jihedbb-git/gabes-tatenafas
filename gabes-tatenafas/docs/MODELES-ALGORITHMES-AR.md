## 1. المسألة العلمية: التنبؤ بالسلاسل الزمنية

**السلسلة الزمنية** هي متتالية قياسات مرتّبة زمنياً: `x_1, x_2, ..., x_t`.
هنا `x_t` = مؤشر AQI (والملوّثات: PM2.5, PM10, NO2, SO2, O3, CO) في اللحظة `t`.

**الهدف**: التنبؤ بالقيمة المستقبلية `x_{t+h}` (الأفق `h` = +1 ساعة، +6 ساعات، +24 ساعة)
انطلاقاً من الماضي القريب. رياضياً نبحث عن دالة `f` بحيث:

```
x_{t+h} ~= f(x_t, x_{t-1}, ..., x_{t-k+1} ; المتغيرات الخارجية)
```

- `k` = حجم نافذة التاريخ (هنا 24 ساعة).
- المتغيرات الخارجية = الطقس (الحرارة، الرطوبة، الرياح)، السياق (منطقة صناعية/ساحلية)، الساعة (دورية).

صيغتان:
- **الانحدار (Regression)**: التنبؤ بقيمة مستمرة (AQI = 87.3).
- **التصنيف (Classification)**: التنبؤ بفئة (جيد / متوسط / سيّئ...).

## 2. المفاهيم الأساسية

### 2.1 النافذة المنزلقة (Sliding window)
نحوّل السلسلة إلى أزواج (مدخل، مخرج):

```
X_i = [x_i, ..., x_{i+23}]   (24 خطوة)   ->   y_i = x_{i+24+h}
```

كل نافذة 24 ساعة تصبح مثالاً للتعلّم. هذا أساس كل النماذج التسلسلية (LSTM، CNN...).

### 2.2 التطبيع / التوحيد القياسي (Normalisation / Standardisation)
الشبكات العصبية تتعلّم بشكل سيّئ إذا اختلفت مقاييس المتغيرات (AQI ~ 0-300، CO ~ 0-2). نطبّق:
- **التوحيد القياسي (z-score)**: `z = (x - mu) / sigma` (متوسط 0، انحراف معياري 1).
- **Min-Max**: `x' = (x - min) / (max - min)` في المجال [0,1]، أو [-1,1] لمخارج `tanh`.

نحفظ `mu, sigma` (أو min/max) الخاصة ببيانات التدريب لتطبيق نفس التحويل عند التنبؤ، ثم نعيد القيمة إلى مقياسها الأصلي (denormalisation).

### 2.3 فرط التعلّم (Overfitting) والتنظيم (Regularisation)
يحدث **فرط التعلّم** عندما يحفظ النموذج ضجيج بيانات التدريب ويعمّم بشكل سيّئ. الحلول العلمية:
- **Dropout**: تعطيل عصبونات عشوائياً أثناء التدريب.
- **التنظيم L1/L2**: معاقبة الأوزان الكبيرة (`+ lambda * ||w||`).
- **الإيقاف المبكّر (Early stopping)**: التوقّف عندما يرتفع خطأ التحقّق.
- **Batch Normalization**: يثبّت ويسرّع التعلّم.

### 2.4 تقسيم التدريب / التحقّق / الاختبار
نفصل البيانات **زمنياً** (لا عشوائياً في السلاسل الزمنية): الماضي -> التدريب، المستقبل -> الاختبار.
هذا يمنع "تسرّب المستقبل" (data leakage).

## 3. نماذج تعلّم الآلة الكلاسيكية

### 3.1 الانحدار الخطي و AR(p) — الانحدار الذاتي
نموذج **الانحدار الذاتي من الرتبة p**، يُرمز AR(p)، يتنبّأ بالقيمة الحالية كتركيبة خطية
من القيم `p` السابقة:

```
x_t = c + phi_1 * x_{t-1} + phi_2 * x_{t-2} + ... + phi_p * x_{t-p} + e_t
```

- `phi_i` = معاملات مُتعلَّمة (المربعات الصغرى).
- `e_t` = ضجيج أبيض (خطأ).
- في المشروع: **AR(7)** (آخر 7 ساعات). بسيط وسريع، يُستخدم كـ **خط أساس (baseline)**
  للحكم إن كانت النماذج المعقّدة تقدّم فعلاً تحسّناً.

### 3.2 الغابة العشوائية (Random Forest)
مجموعة من **أشجار القرار**. الشجرة تقسّم فضاء المتغيرات بقواعد "إذا كانت الخاصية < عتبة".
الغابة العشوائية:
1. تُنشئ N شجرة، كل واحدة تُدرَّب على **عيّنة bootstrap** (سحب مع الإرجاع).
2. في كل عقدة، تختبر فقط **مجموعة فرعية عشوائية** من المتغيرات (إزالة الترابط).
3. **التنبؤ = المتوسط** عبر الأشجار (انحدار) أو التصويت بالأغلبية (تصنيف).

الميزة: قوية، قليلة الضبط، تعطي **أهمية المتغيرات**. إنها من نوع **bagging** (انظر 9.1).

### 3.3 XGBoost — التعزيز التدرّجي الفائق (مفصّل)
XGBoost هو **gradient boosting**: يبني الأشجار **بالتتابع**، وكل شجرة جديدة تصحّح
**الأخطاء المتبقية** للأشجار السابقة.

نموذج جمعي: التنبؤ بعد `T` شجرة هو:

```
y_hat_i = sum_{t=1..T} f_t(x_i)،   f_t ينتمي لفضاء الأشجار
```

في الخطوة `t`، نضيف الشجرة `f_t` التي تُصغّر **الدالة الهدف المُنظَّمة**:

```
L^(t) = sum_i  l( y_i , y_hat_i^(t-1) + f_t(x_i) )  +  Omega(f_t)
Omega(f) = gamma * عدد_الأوراق + (1/2) * lambda * sum_j w_j^2
```

- `l` = دالة الخسارة (مثلاً الخطأ التربيعي للانحدار).
- `Omega` = تعاقب التعقيد (عدد الأوراق، الأوزان `w_j`).

يقوم XGBoost بـ **نشر تايلور من الرتبة الثانية** للخسارة:

```
L^(t) ~= sum_i [ g_i * f_t(x_i) + (1/2) * h_i * f_t(x_i)^2 ] + Omega(f_t)
g_i = المشتقة الأولى للخسارة،  h_i = المشتقة الثانية (Hessienne)
```

**الوزن الأمثل** لورقة `j` (مجموعة الأمثلة `I_j`) هو:

```
w_j* = - ( sum_{i in I_j} g_i ) / ( sum_{i in I_j} h_i + lambda )
```

و **الربح (Gain)** لتقسيم يفصل عقدة إلى يسار (L) / يمين (R):

```
Gain = (1/2) * [ G_L^2/(H_L+lambda) + G_R^2/(H_R+lambda) - (G_L+G_R)^2/(H_L+H_R+lambda) ] - gamma
```

نحتفظ بالتقسيم إذا كان `Gain > 0`. **المعاملات الفائقة المهمة**:
- `n_estimators` (عدد الأشجار)، `max_depth` (العمق)،
- `learning_rate` (eta، تقليص كل شجرة)،
- `subsample`، `colsample_bytree` (عيّنة الصفوف/الأعمدة)،
- `lambda` (L2)، `gamma` (التقليم)، `min_child_weight`.

**لماذا هو قوي لـ AQI**: يلتقط العلاقات **غير الخطية** والتفاعلات (مثلاً "رياح ضعيفة +
منطقة صناعية + ليل -> ذروة SO2") دون الحاجة لتحديدها يدوياً. سريع ودقيق على البيانات الجدولية
(الخصائص = الفجوات الزمنية + الطقس + السياق).

### 3.4 MLP — الإدراك متعدد الطبقات
شبكة عصبية "كثيفة". كل طبقة تحسب `a = activation(W*x + b)`. تكديس عدة طبقات غير خطية (ReLU)
لتقريب دوال معقّدة (نظرية التقريب الشامل). تُدرَّب بـ **الانتشار العكسي** + النزول التدرّجي.
جيّدة للخصائص الجدولية، لكنها تتجاهل الترتيب الزمني (بخلاف LSTM).

## 4. نماذج التعلّم العميق

### 4.1 RNN و LSTM
الـ **RNN** (شبكة تكرارية) تعالج التسلسل خطوة بخطوة محتفظةً بـ **حالة مخفية**
`h_t = activation(W_x x_t + W_h h_{t-1} + b)`. المشكلة: **تلاشي التدرّج**
(vanishing gradient) -> عجز عن حفظ المدى الطويل.

الـ **LSTM** (الذاكرة طويلة-قصيرة المدى) يحل ذلك بـ **خلية ذاكرة** `C_t` وثلاث **بوابات (gates)**
تتحكّم في تدفّق المعلومات:

```
f_t = sigma(W_f [h_{t-1}, x_t] + b_f)      # بوابة النسيان (forget)
i_t = sigma(W_i [h_{t-1}, x_t] + b_i)      # بوابة الإدخال (input)
C~_t = tanh(W_c [h_{t-1}, x_t] + b_c)      # مرشّح الذاكرة
C_t = f_t * C_{t-1} + i_t * C~_t           # تحديث الذاكرة
o_t = sigma(W_o [h_{t-1}, x_t] + b_o)      # بوابة الإخراج (output)
h_t = o_t * tanh(C_t)                       # الحالة المخفية الجديدة
```

- `sigma` = الدالة السينية (قيم 0-1 = "كم نسمح بالمرور").
- بوابة النسيان تسمح بـ **الاحتفاظ** أو **المحو** للمعلومات عبر فترات طويلة.
- مثالي لدورات النهار/الليل للتلوّث.

### 4.2 BiLSTM (LSTM ثنائي الاتجاه)
شبكتا LSTM تقرآن التسلسل في **الاتجاهين** (أمام وخلف)، ثم نجمع:

```
h_t = [ h_t(أمام) ; h_t(خلف) ]
```

كل لحظة تستفيد من سياق **الماضي والمستقبل** ضمن النافذة (أثناء التدريب).
أغنى لالتقاط الشكل الكامل لنوبة تلوّث.

### 4.3 CNN / Conv1D (الالتفاف أحادي البُعد)
طبقة **Conv1D** تمرّر **مرشّحات (نوى)** على طول التسلسل لكشف **أنماط محلية**
(صعود مفاجئ، ذروة، هضبة):

```
(y * w)_t = sum_{j=0..K-1} w_j * x_{t-j}      # التفاف سببي بنواة K
```

- `padding="causal"`: يستخدم الماضي فقط (لا تسرّب من المستقبل).
- يستخرج **الخصائص المحلية** بسرعة قبل تمريرها إلى BiLSTM.

### 4.4 آلية الانتباه Attention و Multi-Head Attention
الـ **Attention** يسمح للنموذج بـ **ترجيح** اللحظات الأكثر فائدة للتنبؤ
(مثلاً: هل قيمة قبل 24 ساعة أهمّ من قيمة قبل 3 ساعات؟).

صيغة الانتباه "scaled dot-product" (Vaswani et al., 2017):

```
Attention(Q, K, V) = softmax( Q * K^T / sqrt(d_k) ) * V
```

- `Q` (استعلام)، `K` (مفتاح)، `V` (قيمة) هي إسقاطات خطية للمدخلات.
- `Q*K^T` = درجات التشابه بين المواضع؛ `softmax` -> أوزان مجموعها 1.
- `sqrt(d_k)` = معايرة تثبّت التدرّج.
- النتيجة = متوسط **مُرجَّح** للقيم `V` حسب الأهمية.

**Multi-Head Attention**: ننفّذ `h` انتباهات بالتوازي (h "رؤوس")، كل واحد يتعلّم نوعاً مختلفاً
من التبعية، ثم نجمعها:

```
MultiHead = Concat(رأس_1, ..., رأس_h) * W_O
رأس_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)
```

في المشروع: **4 رؤوس**. المعاملات الجديدة المُتعلَّمة: مصفوفات الإسقاط `W_i^Q, W_i^K, W_i^V`
(لكل رأس) و `W_O` (الدمج). الميزة: النموذج "ينظر" إلى عدة آفاق زمنية في آنٍ واحد.

### 4.5 بنية CNN + BiLSTM + Attention (نموذج التعلّم العميق في المشروع)
التسلسل (المدخل = نافذة 24 ساعة × 7 متغيرات):

```
Input (24, 7)
  -> Conv1D(32, نواة 3, causal) + BatchNorm     # أنماط محلية
  -> BiLSTM(48, return_sequences=True)           # تبعيات طويلة المدى، اتجاهان
  -> Multi-Head Attention(4 رؤوس)                # ترجيح اللحظات المهمة
  -> BiLSTM(24)                                   # تلخيص التسلسل
  -> Dense(24) -> Dense(1)                        # AQI المتوقّع
```

كل لبنة تقدّم قدرة مكمِّلة: **CNN** (محلي) + **BiLSTM** (زمني) + **Attention** (الأهمية النسبية).
إنها بنية **هجينة** (انظر القسم 9).

## 5. المنطق الضبابي من النوع الثاني (Fuzzy Type-2)

يَنمذج **المنطق الضبابي** عدم اليقين بدرجات انتماء في [0,1] (مثلاً: AQI بقيمة 95 هو "متوسط قليلاً،
سيّئ قليلاً"). نظام الاستدلال الضبابي بأربع مراحل:
1. **التضبيب (Fuzzification)**: تحويل القيم الصافية إلى درجات انتماء (دوال مثلثية/غاوسية).
2. **القواعد**: "إذا كان PM2.5 مرتفعاً وكانت الرياح ضعيفة فإن الخطر قوي".
3. **الاستدلال (Inference)**: دمج القواعد (min/max، أو الضرب).
4. **إزالة التضبيب (Defuzzification)**: العودة إلى قيمة صافية (مركز الثقل).

**النوع الثاني (Type-2)**: هنا دوال الانتماء نفسها تحمل **عدم يقين** ("بصمة عدم اليقين"،
FOU = Footprint of Uncertainty). بدل درجة واحدة، لدينا **مجال** من الدرجات. هذا يعالج بشكل أفضل
**ضجيج المستشعرات** وتباين مصادر الـ API. مرحلة إضافية: **تقليل النوع (type-reduction)**
(مثلاً خوارزمية Karnik-Mendel) قبل إزالة التضبيب.

الفائدة: متانة أمام البيانات غير الدقيقة/المتناقضة بين AccuWeather و WAQI و IQAir.

## 6. النماذج التوليدية

### 6.1 المُرمِّز الذاتي (Autoencoder, AE)
شبكة تتعلّم **ضغط ثم إعادة بناء** مدخلاتها:

```
z = Encodeur(x)      # رمز كامن مضغوط (بُعد صغير)
x_hat = Decodeur(z)  # إعادة البناء
الخسارة = || x - x_hat ||^2   (خطأ إعادة البناء، MSE)
```

الـ **الرمز الكامن** `z` يلتقط "الشكل الجوهري" لتسلسل 24 ساعة (الدورة اليومية، الذُرى).
مفيد لـ: إزالة الضجيج، كشف الشذوذ، و **التوليد** (عبر المُفكِّك decodeur).

### 6.2 GAN و CGAN
الـ **GAN** (شبكة توليدية تخاصمية) يُواجه شبكتين:
- **المولّد G**: يحوّل ضجيجاً عشوائياً `z` إلى بيانات اصطناعية.
- **المُميِّز D**: يميّز الحقيقي عن المزيّف.

لعبة **minimax** (Goodfellow, 2014):

```
min_G max_D  E_x[log D(x)] + E_z[log(1 - D(G(z)))]
```

يتحسّن G حتى "يخدع" D -> يولّد بيانات واقعية.

الـ **CGAN** (Conditional GAN، Mirza & Osindero, 2014) يضيف **شرطاً** `c`
(الفصل، الساعة، السياق الصناعي) لمدخل G و D:

```
G(z, c) -> عيّنة مشروطة ؛   D(x, c) -> حقيقي/مزيّف بمعلومية c
```

هكذا نولّد تسلسلات "لهذه المنطقة، لهذه الساعة".

### 6.3 AE-CGAN (نموذجنا) — دمج AE + CGAN
المشكلة: تدريب GAN مباشرة على تسلسلات 24 ساعة متعددة المتغيرات مع **قلّة البيانات الحقيقية**
غير مستقر. الحل **AE-CGAN**:
1. **مُرمِّز ذاتي** يتعلّم أولاً الشكل الحقيقي للتسلسلات (encodeur -> `z`، decodeur).
2. نرمّز كل التسلسلات الحقيقية -> سحابة **رموز كامنة** حقيقية.
3. الـ **CGAN يعمل في الفضاء الكامن** (أصغر، أكثر استقراراً): G يولّد رموزاً كامنة جديدة مشروطة؛
   D يقارنها بالرموز الحقيقية.
4. الـ **decodeur** يحوّل الرموز الجديدة إلى تسلسلات AQI اصطناعية واقعية.

الفائدة العلمية: التوليد في فضاء **كامن مضغوط** يثبّت التعلّم ويعطي بيانات مُعزَّزة أقرب للواقع
-> نماذج أفضل (خاصة LSTM/BiLSTM).
ضمانة الأمانة: إذا كانت منطقة تملك نقاطاً حقيقية قليلة جداً (< 32)، لا نُدرِّب شبكة (غير موثوقة)؛
ننتقل إلى مولّد **إحصائي** مُعلَّم بوضوح.

## 7. القابلية للتفسير (XAI): SHAP، Deep-SHAP، LIME

نموذج دقيق لكنه "صندوق أسود" غير مقبول لقرار يخصّ الصحة العامة. تجعل الـ XAI (الذكاء القابل للتفسير)
التنبؤات **قابلة للتفسير**.

### 7.1 SHAP (SHapley Additive exPlanations)
مبني على **قيم Shapley** من نظرية الألعاب: نُسند لكل متغير **مساهمته المتوسطة** في التنبؤ،
عبر كل التحالفات الممكنة للمتغيرات:

```
phi_j = sum_{S subset F\{j}}  [ |S|! (|F|-|S|-1)! / |F|! ] * [ f(S U {j}) - f(S) ]
```

- `phi_j` = أهمية (بإشارة) المتغير `j`: موجبة = يدفع AQI للارتفاع.
- خاصية **الجمعية**: `التنبؤ = القيمة_الأساسية + sum_j phi_j`.
- الرسوم: **beeswarm** (الأثر العام لكل متغير)، **waterfall** (تفكيك تنبؤ فردي).

### 7.2 Deep-SHAP
نسخة من SHAP مُحسَّنة للـ **الشبكات العميقة** (تدمج SHAP مع DeepLIFT): تنشر المساهمات
طبقة بطبقة، وهو أسرع بكثير من الحساب الدقيق لقيم Shapley (الأسّي). تُستخدم لتفسير نموذج
التعلّم العميق (CNN-BiLSTM-Attention).

### 7.3 LIME (Local Interpretable Model-agnostic Explanations)
يفسّر **تنبؤاً واحداً** بتقريب النموذج المعقّد محلياً بـ **نموذج خطي بسيط** حول النقطة المراد
تفسيرها (نُشوّش المدخل، نلاحظ المخرج، نُلائم انحداراً مُرجَّحاً بالقرب). "Model-agnostic" = يعمل
مع أي نموذج.

## 8. التعلّم الفيدرالي (Federated Learning)

المبدأ: تدريب نموذج **دون تجميع البيانات مركزياً**. كل **منطقة/عميل** يُدرِّب محلياً على بياناته
الخاصة، ثم نُجمِّع **الأوزان فقط** على خادم مركزي. خوارزمية **FedAvg** (McMahan, 2017):

```
لكل جولة r = 1..R :
   1. الخادم يرسل الأوزان العامة w_r لكل عميل k.
   2. كل عميل يُدرِّب محلياً -> w_r^k.
   3. تجميع مُرجَّح بحجم البيانات n_k :
        w_{r+1} = sum_k ( n_k / n_total ) * w_r^k
```

- **الجولات (Rounds)** = عدد دورات المزامنة.
- **الهدف في المشروع**: محاكاة أن كل منطقة بقابس تحتفظ ببياناتها محلياً (الخصوصية) مع الاستفادة
  من نموذج مشترك. مقياس المتابعة: F1 لكل جولة.

## 9. الدمج الهجين: الجمع بين نموذجين أو ثلاثة أو أكثر

### 9.1 المبادئ العامة للتعلّم التجميعي (Ensemble)
دمج عدة نماذج يقلّل الخطأ إذا كانت أخطاؤها **غير مترابطة** (تخطئ في حالات مختلفة). أربع عائلات:

- **Bagging** (مثل Random Forest): تدريب N نموذج على عيّنات bootstrap، ثم **المتوسط**.
  يقلّل **التباين (variance)**.
- **Boosting** (مثل XGBoost): نماذج **متتابعة**، كل واحد يصحّح أخطاء سابقه.
  يقلّل **الانحياز (biais)**.
- **Voting / Averaging**: متوسط (انحدار) أو تصويت (تصنيف) لنماذج مختلفة.
  - المتوسط البسيط: `y = (1/M) sum_m y_m`.
  - **المتوسط المُرجَّح**: `y = sum_m alpha_m * y_m`، بشرط `sum alpha_m = 1`. تُعطى الأوزان
    `alpha_m` حسب الأداء (مثلاً عكسياً مع RMSE).
- **Stacking (التكديس)**: **نموذج فوقي (meta-model)** يتعلّم دمج مخارج النماذج الأساسية.
  تنبؤات نماذج المستوى 0 تصبح **خصائص** لنموذج المستوى 1:

```
المستوى 0 : y1 = M1(x), y2 = M2(x), y3 = M3(x)
المستوى 1 : y_final = MetaModele(y1, y2, y3)   # مثلاً انحدار، أو MLP
```

المعاملات **الجديدة** في التكديس هي أوزان/معاملات النموذج الفوقي.

### 9.2 XGBoost + Fuzzy (الدمج في المشروع)
طريقتان علميتان لدمجهما:

**(أ) الضبابي كمعالجة أولية (هندسة خصائص ضبابية)**
ينتج المنطق الضبابي **متغيرات ضبابية** (درجة الانتماء إلى "PM2.5 مرتفع"، "رياح ضعيفة"،
"خطر صناعي") تُضاف إلى خصائص XGBoost:

```
features_XGB = [ فجوات AQI، الطقس، ... ، mu_PM25_مرتفع، mu_رياح_ضعيفة، mu_خطر_قوي ]
```

الميزة: يستقبل XGBoost معرفة خبير (القواعد الضبابية) إضافةً للبيانات الخام.

**(ب) دمج المخارج (مُرجَّح)**
يعطي XGBoost تنبؤاً `y_xgb`؛ ويعطي النظام الضبابي **مؤشر خطر** `y_fuzzy`. نجمع:

```
y_final = alpha * y_xgb + (1 - alpha) * y_fuzzy
```

- `alpha` (معامل جديد، في [0,1]) يضبط الثقة النسبية. نختاره بالتحقّق (الذي يُصغّر RMSE)،
  أو ديناميكياً حسب السياق (مثلاً وزن أكبر للضبابي عند تناقض المستشعرات).
- **كيف يعمل**: يلتقط XGBoost العلاقات الإحصائية الدقيقة؛ ويقدّم الضبابي المتانة والقابلية
  للتفسير في المناطق غير المؤكّدة. الدمج يُنعِّم الأخطاء.

### 9.3 BiLSTM + Attention (الدمج في المشروع)
ينتج BiLSTM متتالية حالات مخفية `h_1..h_24`. بدون انتباه، غالباً نحتفظ فقط بالحالة الأخيرة
`h_24` (فقدان معلومات). **مع الانتباه**، نحسب أوزاناً `a_t` (مجموعها 1) و **متجه سياق**:

```
score_t = دالة(h_t)              # أهمية اللحظة t
a_t = softmax(score_t)           # أوزان مُطبَّعة
السياق = sum_t a_t * h_t         # ملخّص مُرجَّح لكامل التسلسل
y = Dense(السياق)               # التنبؤ
```

- **المعاملات الجديدة**: أوزان طبقة الانتباه (مصفوفات Q/K/V أو متجه الدرجة) — تُتعلَّم مع
  BiLSTM معاً عبر الانتشار العكسي.
- **كيف يعمل**: يشير الانتباه إلى **أي لحظات** من نافذة 24 ساعة كان لها أكبر وزن (مثلاً ذروة
  قبل 6 ساعات). هذا **يزيد الدقة** ويوفّر تفسيراً (خريطة انتباه). إنه دمج "تسلسلي" (لبنة تُغذّي الأخرى).

### 9.4 التجميع الديناميكي ("FULL SYSTEM" في المشروع)
يدمج النظام النهائي عدة نماذج (XGBoost+Fuzzy، RF، MLP، BiLSTM+Attention...) عبر **متوسط
مُرجَّح ديناميكي**: تُعاد حساب الأوزان `alpha_m` حسب الأداء الحديث لكل نموذج (النموذج الذي
ينحرف ينخفض وزنه). إنه **تصويت مُرجَّح تكيّفي** — يميل ليكون على الأقل بجودة أفضل عضو فيه،
مع استقرار أكبر.

## 10. مقاييس التقييم (مفصّلة وعلمية)

الرموز: `y_i` = القيمة الحقيقية، `y_hat_i` = القيمة المتوقّعة، `n` = عدد الأمثلة.

### 10.1 مقاييس الانحدار (التنبؤ بقيمة AQI)

**MAE — متوسط الخطأ المطلق**
```
MAE = (1/n) * sum_i | y_i - y_hat_i |
```
متوسط الفروق بالقيمة المطلقة. بنفس وحدة AQI. غير حسّاس كثيراً للقيم المتطرّفة.

**RMSE — الجذر التربيعي لمتوسط مربّع الخطأ**
```
RMSE = sqrt( (1/n) * sum_i ( y_i - y_hat_i )^2 )
```
- بسبب التربيع -> **يعاقب بشدّة الأخطاء الكبيرة** (مفيد: تفويت ذروة تلوّث خطير). بنفس وحدة AQI.
- **RMSE >= MAE** دائماً. فارق كبير بينهما يدلّ على أخطاء متفاوتة جداً.
- **التفسير**: RMSE = 4.9 يعني أننا نخطئ في المتوسط (التربيعي) بنحو 5 نقاط AQI. كلما **قلّ** كان أفضل.

**MAPE — متوسط النسبة المئوية للخطأ**
```
MAPE = (100/n) * sum_i | (y_i - y_hat_i) / y_i |
```
خطأ نسبي بالنسبة المئوية. سهل التفسير، لكنه غير مستقر عندما تقترب `y_i` من الصفر.

**sMAPE — MAPE المتماثل**
```
sMAPE = (100/n) * sum_i  | y_i - y_hat_i | / ( (|y_i| + |y_hat_i|) / 2 )
```
نسخة متماثلة ومحدودة، تصحّح عيب MAPE قرب الصفر.

**R2 — معامل التحديد**
```
R2 = 1 - ( sum_i (y_i - y_hat_i)^2 ) / ( sum_i (y_i - y_bar)^2 )
```
- `y_bar` = متوسط القيم الحقيقية. يقيس **نسبة التباين المُفسَّر** بالنموذج.
- R2 = 1 -> مثالي؛ R2 = 0 -> بجودة التنبؤ بالمتوسط؛ R2 < 0 -> أسوأ من المتوسط.

### 10.2 مقاييس التصنيف (التنبؤ بفئة جودة الهواء)
مبنية على **مصفوفة الالتباس**: VP (إيجابيات صحيحة)، VN، FP (إيجابيات خاطئة)، FN.

**Accuracy (الدقة الإجمالية)** — غالباً "accu"
```
Accuracy = (VP + VN) / (VP + VN + FP + FN)
```
نسبة التنبؤات الصحيحة. **فخّ**: مضلِّلة عند اختلال توازن الفئات (مثلاً 95% أيام "جيدة" ->
نموذج غبي يقول دائماً "جيد" يحقّق 95% دقة لكنه يفوّت كل الذُرى الخطيرة). لذا أهمية F1.

**Precision (الدقّة)**
```
Precision = VP / (VP + FP)
```
من بين إنذارات "سيّئ" الصادرة، كم كان صحيحاً؟ (تجنّب الإنذارات الكاذبة).

**Recall (الاستدعاء / الحساسية)**
```
Recall = VP / (VP + FN)
```
من بين نوبات "سيّئ" الحقيقية، كم اكتُشِفت؟ (تجنّب الإغفالات الخطيرة).

**F1-score** — المتوسط التوافقي للدقّة والاستدعاء
```
F1 = 2 * (Precision * Recall) / (Precision + Recall)
```
- يوازن بين الدقّة والاستدعاء. **متين أمام اختلال الفئات** -> المقياس الأهمّ للصحة (نريد
  إنذارات كاذبة قليلة وإغفالات قليلة معاً).
- `macro-F1` = متوسط F1 عبر الفئات (يعامل كل فئة بالتساوي).

**AUC-ROC — المساحة تحت منحنى ROC**
منحنى ROC يرسم **معدل الإيجابيات الصحيحة** (recall) مقابل **معدل الإيجابيات الخاطئة** عند تغيير
عتبة القرار. الـ **AUC** = المساحة تحت المنحنى، في [0,1]:
- 0.5 = صدفة، 1.0 = مثالي. يقيس القدرة على **الترتيب** الصحيح، بغضّ النظر عن العتبة.

### 10.3 مقاييس النظام

**زمن الاستجابة (Latence, lat)**
زمن حساب تنبؤ واحد (بالمللي ثانية، مثل `avg_latency_ms`). حاسم للـ **الزمن الحقيقي**: نموذج
دقيق جداً لكنه بطيء لا يصلح لإنذارات كل دقيقة. نوازن دائماً بين **الدقة وزمن الاستجابة**.

### 10.4 مقاييس النماذج التوليدية (GAN / AE-CGAN)

**Coverage score (التغطية)**
يتحقّق أن البيانات المولّدة تغطّي نفس مجال قيم الحقيقي (مثلاً على 10 مجالات AQI، نفس الإشغال).
يكشف **انهيار الأنماط (mode collapse)** (يولّد GAN نوعاً واحداً فقط من المخارج).

**مسافة Frechet (FID مبسّطة)**
تقارن **التوزيعات** الحقيقية والمولّدة عبر متوسّطاتها/تبايناتها المشتركة:
```
FID = || mu_r - mu_g ||^2 + Tr( Sigma_r + Sigma_g - 2 (Sigma_r Sigma_g)^{1/2} )
```
كلما **قلّت** كان الاصطناعي أشبه بالحقيقي.

**تشابه التوزيع / الأمانة (fidelity)**
درجة (0-1) تقيس مدى مطابقة إحصاءات الاصطناعي للحقيقي. نعرضها لـ **إثبات** أن تعزيز البيانات
مفيد وغير مضلِّل.

## 11. سلسلة التنبؤ الكاملة (من المستشعر إلى الإنذار)

```
1. الجمع        : APIs (AccuWeather + WAQI + IQAir) -> دمج مُرجَّح -> جدول api_readings
                  (استيراد آلي كل دقيقة).
2. التعزيز      : AE-CGAN يولّد تسلسلات واقعية -> api_readings_augmented
                  (يسدّ نقص البيانات للتدريب).
3. الخصائص      : نافذة 24 ساعة + فجوات + طقس + سياق + ساعة دورية + (متغيرات ضبابية).
4. التدريب      : XGBoost, RF, MLP, BiLSTM+Attention, CNN-BiLSTM-Attention... (train_all.py)
                  -> المقاييس في model_performance ؛ أدوات التعلّم العميق في dl_artifacts.
5. الدمج        : تجميع ديناميكي (متوسط مُرجَّح) -> التنبؤ النهائي +1س/+6س/+24س.
6. التفسير      : SHAP / Deep-SHAP (beeswarm, waterfall) + خريطة انتباه.
7. التقييم      : RMSE / MAE / R2 (انحدار) ؛ Accuracy / F1 / AUC (تصنيف) ؛ زمن الاستجابة.
8. القرار       : تصنيف (جيد..خطير) + إنذارات.
```

**الهدف النهائي**: توقّع ذُرى التلوّث في قابس بشكل **موثوق وحقيقي وقابل للتفسير**، لحماية الصحة
العامة — دون تقديم أي بيانات مزيّفة على أنها حقيقية أبداً.
